# 新闻传播通用招聘要求 · 候选数据

- [journalism-general-v1.json](journalism-general-v1.json) 是供数据库导入的候选种子。每条记录包含稳定标识、职业标识、工作任务或能力类别、跨行业表述及来源标识。
- [journalism-sources-v1.json](journalism-sources-v1.json) 索引用于复核的原始招聘链接、表格行号及 Word 章节。表格行号按 Excel 界面计数，包含标题行。链接状态来自附件标注，本次没有独立核验原始网页。相同链接可对应多条公告条目，也可能是不同职业重复引用同一岗位，审核时应按实际公告与岗位标识去重。
- 岗位场景已归纳为岗位本身的通用任务与能力。例如垂直行业的新品项目归纳为市场机会、目标受众、渠道协同和效果复盘。雇主、细分行业、学历、资质、工龄和实习出勤条件未进入通用要求字段。可准备的作品归为准备建议。仅来自 Word 的条目应在审核时补充可核验出处。
- 种子导入时为待审核。用户确认此次归纳无需独立确认来源后，从已批准的数据库快照导出了公开职业参考。原始索引和种子文件仍在静态资源根之外。公开参考未用于样本统计或 AI 分析。
