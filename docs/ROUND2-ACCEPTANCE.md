## 实机验收建议

1. Chrome/Edge/Safari：1366×768、1440×900、1920×1080，打开测评，检查最长题目、全部四选项、反馈及前后按钮；选择答案不跳位，下一题可直接作答。
2. 320/390/768px：封面无关键文字遮挡，路径标签与星系预览可操作，结果雷达/表格可读，按钮不覆盖内容。
3. Tab、Enter、Esc和设备减少动态效果设置；职业预览关闭、折叠内容、角色循环与SVG流动。
4. 两专业来回切换、路径筛选、查看全部职业；进入相邻职业，再用浏览器返回；完整测评及刷新恢复。
5. 修改答案后再次进入四部分结果，角色、雷达、差距和建议同步变化。
