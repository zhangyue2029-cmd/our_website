# 两专业入口调整验收

本轮以最近交付的 quxiang-bloom-capsule.zip 为基线，仅调整前两页入口及必要的状态、路由衔接。

| 范围 | 结果 |
|---|---|
| 第二页只保留两个胶囊 | 汉语言文学、新闻传播；不显示其他门类或「待补充」项；自动化验证通过 |
| 花朵共享转场与切换 | 原节点收拢、入轨、双人物与光晕切换保留；模拟控制器测试通过 |
| 两项居中与轮换 | 轨道根据视口补足两侧留白，支持两项循环；实际排版待浏览器验证 |
| 点击探索 | 直接选取原 majorId 并进入原 focus；不新增中间专业列表页 |
| 后续页面不变 | main.js 中 renderFocus 至 renderMine 的完整渲染代码与上一交付包逐字节一致 |
| 业务数据不变 | majors、directions、careers、questions、skills、market、api 与计分、画像组件、原样式均未改动；21 项受保护文件校验通过 |
| 状态恢复 | 浏览两个胶囊保留回答；进入相同专业保留回答；进入不同专业沿用原重置规则 |
| 旧链接兼容 | 旧 majors 路由返回第二页；旧 category 值优先依据已有 majorId 恢复 |
| 全流程回归 | 原 14 职业、学习领域、星系、测评、画像及历史路由测试通过 |
| 浏览器验证 | 环境无可用的浏览器控制能力，未进行真实桌面/手机排版、流畅度和触屏验收 |

## 修改范围

- src/data/categories.js：两项视觉入口一对一映射到原专业；未修改 src/data/majors.js。
- src/immersive/view.js、controller.js：两个胶囊的标签、说明、轨道留白。
- src/styles/immersive.css：汉语言文学长标题字号适配，仅作用于新入口。
- src/main.js：探索按钮直接使用原专业选择规则；兼容旧中间页链接；后续页面渲染不变。
- src/lib/store.js、router.js：默认入口与状态参数对应两个原专业。
- 入口专项测试及文档相应更新。

只在前两页的 immersive.css 增加长专业名标题适配；本轮没有修改图片、后续页面组件、原专业职业数据或评分算法。完整源文件核对清单见 TWO-ENTRIES-PRESERVATION.json。
